# Astro-Vastu zodiac-to-zone research (19 Nov 2026)

Result: NO reliable public source was found for the owner's sign-to-zone table. No value was corrected. The owner's file is kept as `data/astro_vastu_zodiac_directions_owner_original.csv`; `data/astro_vastu_zodiac_directions.csv` is currently identical (change log below is empty on purpose).

## What was checked (web search plus page reads)
- [sohemvastu: 16 directions, 32 entrances](https://sohemvastu.blogspot.com/2026/05/16-directions-32-entrances-and-45.html): 32 entrances of 11.25 degrees each, 16 directions of 22.5 degrees (so two entrances per direction). Names N3, N4, N5, E3, E4, S3, S4, W3, W4 as auspicious; N1, N2, N6, N7, N8, E1, E2 and the south-west ones as not. No zodiac link and no full code table.
- [numerology4us: Astro Vastu](https://numerology4us.blogspot.com/2025/08/astro-vastu.html): maps planets (not signs) to directions: Sun East, Moon NW, Mars South, Mercury North, Jupiter NE, Venus SE, Saturn West, Rahu SW, Ketu centre.
- [bricknbolt: facing house by rashi](https://www.bricknbolt.com/blogs-and-articles/home-design-guide/which-facing-house-is-good-for-all-rashis) and similar sites: give house-facing or lucky directions per sign in 4/8 directions, not 32-zone codes. Only Aries = East lines up with our table. Other sites disagree (for example Sagittarius lucky direction NW, not NE).
- Several searches for the exact zone codes (E4-E6, N2-N3 and so on) next to sign names returned nothing. The Buddhist text "Mahavastu" is unrelated.
