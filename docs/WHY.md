# Why this exists
Goal (Rajat): comprehensive database of astrology methods (Bhrigu, Lal Kitab, KP, Vedic/Parashari, Jaimini, K.N. Rao, Western) so four engines can work: events, timing, do/don't, remedies. Tested on famous people, used for family charts. Aspiration: 90% accuracy. Rajat: "Unknown is unknown. We need to build."
## Design
- Software = plain code. Output = detailed report per method and per technique, with evidence.
- Stage 1 evaluate techniques; Stage 2 apply to chart; Stage 3 AI infers from reports only.
- Sequence of analysis: A house<->sign equivalence (several signs per house), B natal charts D1-D60, Narayana, sayana, KP; C panchang of the day; D transit of the day.
## Honest status
Measured skill so far is zero (see RESULTS.md). The 90% target is an aspiration, not a result.
