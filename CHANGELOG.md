# Changelog
Owner rule: every change bumps the version and updates this file, version.json and the knowledge doc in the same PR. Versions: MAJOR.MINOR.PATCH.

## 0.2.0 - 2026-11-22
- Added house-to-body-part table (Kalapurusha, 12 houses/signs): `data/house_body_parts.csv`, `core/body_parts.py` (by house number and by sign, multi-sign houses with major/minor shares).
- Added avoid-colours tables: `data/lagna_avoid_colours.csv` (all 12 lagnas, functional malefics) and `data/planet_avoid_colours.csv` (natural enemies), `core/avoid_colours.py`.
- Added D1 migrations `migrations/0002_body_parts_avoid_colours_schema.sql` and `0003_body_parts_avoid_colours_seed.sql` (generated by `tune/build_seed_sql.py`). Not applied to any live database.
- Added `tests/test_body_parts_avoid_colours.py` (12-houses and 12-lagnas coverage, hand-typed expectations, in-memory sqlite check of the migrations, seed-in-sync check) and wired it into `tests/run_all.sh`.
- Every row is `DEFAULT, owner to confirm`; list in `docs/BODY_PARTS_AVOID_COLOURS.md`. Version rule: the knowledge doc is now `docs/BODY_PARTS_AVOID_COLOURS.md` (the earlier doc `docs/PLANET_SIGN_NEGATIVES.md` stays).

## 0.1.0 - 2026-11-21
- First tracked version (CHANGELOG.md and version.json created).
- Added owner table of planet-in-sign and planet-aspect negatives with colour remedies: `data/planet_sign_negatives.csv` (13 rows).
- Added `core/planet_negatives.py`: flags a planet negative by placement or by its listed aspects, returns remedy colours (single or combination) for body, house, office.
- Added `tests/test_planet_negatives.py` (all 13 rules x 12 signs, every aspect case, no-false-positive, input handling, loader checks) and wired it into `tests/run_all.sh`.
- Knowledge doc: `docs/PLANET_SIGN_NEGATIVES.md` (table, readings chosen, questions for the owner).
